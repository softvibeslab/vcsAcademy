## 📅 PASO 2: Daily Performance

### 2.1 Registrar Ventas (Sales Grid)
```
1. Navegar a: http://localhost:3001/daily-performance
2. Click en "Sales Grid" tab
3. Click en Day 1 del grid
4. Completar formulario:
   - Socio: "John Smith"
   - Volume: 1200
   - % Enganche: 20
   - % Comisión: 18.5
   - Daily Tip: "Great closing today!"
5. Click "Save Record (+10 pts)"
6. Repetir para Days 2-5 con diferentes montos
```

### 2.2 Marcar Atributos (Attributes)
```
1. Click en "Attributes" tab
2. Ver 7 atributos disponibles
3. Para cada atributo:
   a. Click en la card del atributo
   b. Marcar "Achieved" checkbox
   c. Agregar note: "Crushed it today!"
   d. Click "Save Attribute"
4. Hacer esto para:
   - ✓ ATTITUDE (+10 pts)
   - ✓ COURAGE (+10 pts)
   - ✓ FOCUS (+10 pts)
   - ✓ TRAINING (+15 pts)
   - ✓ DISCIPLINE (+20 pts)
   - ✓ PERSISTENCE (+15 pts)
   - ✓ COMMITMENT (+25 pts)
5. Al completar los 7 → DAILY COMBO +100 pts!
```

### 2.3 Completar Daily Challenge
```
1. Click en "Challenges" tab
2. Ver el desafío del día (ej: "Monday Focus")
3. Slider: Mover a 3/3 tareas completadas
4. Agregar note: "Focused and crushed it!"
5. Click "Save Progress" → +25 pts
```

## 📈 PASO 3: Analytics

### 3.1 Ver Efficiency Dashboard
```
1. Navegar a: http://localhost:3001/analytics
2. Ver "Efficiency" tab
3. Observar métricas calculadas automáticamente:
   - Efficiency Score: calculado de tus datos
   - Total Volume con trend vs mes anterior
   - Closing Rate con porcentaje
   - Avg Sale con comparativas
   - Days Active
4. Ver "Performance Insights" con recomendaciones
```

### 3.2 Ver Predictions
```
1. Click en "Predictions" tab
2. Ver "Goal Probability" gauge
3. Observar:
   - Predicted Revenue (basado en tu performance)
   - Predicted Gap
   - Performance Trend (últimos 7 días)
   - Daily Pace Needed
4. Leer "AI Recommendations"
```

### 3.3 Generar Monthly Report
```
1. Click en "Monthly Report" tab
2. Ver reporte automático con:
   - Executive Summary
   - Key Achievements
   - Weekly Breakdown
   - Streaks & Records
   - Badges Earned
3. Click "Export Report" (funcionalidad futura)
```

## 🎯 PASO 4: Strategy Planning

### 4.1 Crear SMART Goal
```
1. Navegar a: http://localhost:3001/strategy
2. Click en "SMART Goals" tab
3. Click "New Goal"
4. Completar formulario:
   Title: "Close $20,000 in sales this month"
   Category: 💰 Sales
   Timeframe: Short-term
   Target Value: 20000
   Description: "Focus on premium packages"
   Deadline: 2025-04-30
   Action Steps:
     1. Make 10 prospecting calls daily
     2. Follow up with all leads within 24h
     3. Complete 2 training modules
     4. Attend daily standup meetings
     5. Review progress weekly
   Motivation: "This will take me to Stage 3!"
5. Click "Create Goal"
```

### 4.2 Crear Action Plan
```
1. Click en "Action Plan" tab
2. Click "New Action"
3. Completar formulario:
   Title: "Call 5 Cold Leads"
   Category: 📞 Prospecting
   Priority: 🔴 High
   Due Date: Today
   Estimated Time: 2 hours
   Description: "Focus on quality conversations"
4. Click "Create Action"
5. Crear 3-5 acciones más
```

### 4.3 Ver Training Recs
```
1. Click en "Training" tab
2. Ver "Recommended" tab
3. Observar módulos recomendados basados en tu performance
4. Ver "In Progress" y "Completed" tabs
5. Click "Start Module" en cualquier módulo
```

### 4.4 Crear Commitment
```
1. Click en "Commitments" tab
2. Click "New Commitment"
3. Completar formulario:
   Title: "Exercise 30 minutes daily"
   Type: Daily
   Category: 💪 Health
   Start Date: Today
   Target Value: 30 (days)
   Check-in Days: Mon-Fri selected
4. Click "Create Commitment"
5. Crear 2-3 commitments más
```
