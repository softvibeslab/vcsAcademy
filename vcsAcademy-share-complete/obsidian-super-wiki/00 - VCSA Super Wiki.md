# VCSA Super Wiki

Esta carpeta es un vault base para Obsidian sobre **Vacation Sales Club Academy**. Su objetivo es convertir un repo grande, con varias apps y mucha documentación dispersa, en una capa de navegación rápida.

## Qué contiene

- Un mapa ejecutivo del proyecto
- Un mapa del repositorio
- Notas por capa técnica
- Un atlas de documentación existente
- Una nota de estado real del proyecto
- Una guía para importarlo a Obsidian

## Foto rápida del repo

- Aproximadamente `747` archivos útiles excluyendo `.git`, `node_modules`, `dist`, `build` y caches
- `195` archivos Markdown dentro del repo
- Núcleo técnico actual en `backend/` y `frontend/`
- App móvil nueva en `apps/mobile/`
- App alterna orientada a módulos academy en `alternate-project/`
- Superficies secundarias o legacy en `vcsa-mobile/`, `vcsa-insight/` y `netlify-deploy/`

## Cómo navegar esta wiki

1. Empieza por [[01 - Executive Summary]]
2. Luego revisa [[02 - Repository Map]]
3. Si vas a tocar producto, abre [[03 - Product Surface Areas]]
4. Si vas a tocar código, sigue con [[04 - Backend & API]], [[05 - Frontend Web]] y [[06 - Mobile Apps]]
5. Si necesitas contexto histórico, usa [[10 - Documentation Atlas]]
6. Si vas a tomar decisiones de cleanup o priorización, usa [[11 - Current State & Risks]]

Esta wiki intenta ser la capa de orientación más útil, pero no reemplaza el código. Si encuentras conflicto entre una nota y el código, toma el código como fuente final y usa [[10 - Documentation Atlas]] para rastrear de dónde salió el contexto previo.
