🔧 SOLUCIÓN DE PROBLEMAS

  1. Si un módulo muestra "Error 200 pero mismo contenido":
    • Abre DevTools (F12)
    • Ve a Console tab
    • Busca errores de JavaScript
    • Verifica que el título de la página sea diferente
  2. Si todos los módulos redirigen al onboarding:
    localStorage.setItem('vcsa_onboarding_completed', 'true'); location.reload();
  3. Si hay errores de CORS:
    • Espera 2 minutos después de iniciar Docker
    • Verifica que el backend esté corriendo: docker ps | grep vcsa
