⚠️ SOLUCIÓN DE PROBLEMAS DE CONEXIÓN

  1. Si el frontend no carga:
    Verifica que el contenedor esté corriendo: docker ps | grep vcsa-web-local
  2. Si hay errores de CORS:
    Espera 2 minutos después de iniciar los contenedores
  3. Si el backend no responde:
    Reinicia el backend: docker-compose -f docker-compose.local.yml restart vcsa-api-local
  4. Si MongoDB no conecta:
    Verifica que el contenedor esté healthy: docker ps | grep vcsa-db-local
  5. Para reiniciar todo:
    ./INICIAR_LOCAL.sh
